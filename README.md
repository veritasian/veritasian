### About

I build **practical tools at the intersection of AI and everyday workflow** — Obsidian plugins, CLI bridges, and learning frameworks. My work focuses on taking complex engineering problems (protocol translation, LLM integration) and wrapping them into one-click experiences that anyone can use.

- 🔭 Currently: Obsidian plugins + Codex CLI tooling
- 🌍 Languages: English, 中文
- 🛠 Stack: TypeScript · Swift · Go · Shell · Python
